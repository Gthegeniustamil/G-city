# G City - Township Style Prototype

A simple original browser-based city-building game prototype.

## Run
Open `index.html` in Chrome/Edge/Firefox.

## Included
- 10x10 buildable town map
- House, Farm, Bakery, Market, Road and Tree
- Coins, XP, levels and population
- Bakery order/reward
- Town income collection
- Save game with localStorage
- Reset/new game
- Mobile responsive UI

## Next upgrade ideas
Firebase login/cloud save, animated workers, crops with timers, trucks/trains, missions, decorations, sound, multiple maps, achievements and Android packaging.
